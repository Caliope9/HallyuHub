Política de privacidad

Última actualización: 8 de septiembre de 2026

Vigencia: 8 de septiembre de 2026

El responsable del servicio es HallyuHub. Contacto: soporte@hallyuhub.net.

Datos que usamos

Podemos usar email, nombre, username, país, región o ciudad opcional, avatar, biografía, contenido publicado, comentarios, mensajes, follows, reacciones, reportes, bloqueos y datos técnicos mínimos necesarios para operar la aplicación.

Finalidades

Usamos estos datos para autenticar cuentas, mostrar perfiles y contenido, prestar funciones sociales, almacenar archivos, moderar reportes, prevenir abuso o fraude, responder soporte y cumplir obligaciones legales aplicables.

Visibilidad

El contenido que publicás puede ser visible para otros usuarios según la configuración y el tipo de contenido. Los mensajes privados se muestran a los integrantes de la conversación, con controles técnicos y revisión limitada cuando exista un reporte de abuso.

Proveedores

Usamos Supabase como proveedor técnico para autenticación, base de datos y almacenamiento. Esta versión no usa GPS, OpenAI, publicidad ni analytics activos.

Retención y eliminación

Conservamos los datos durante el tiempo necesario para prestar HallyuHub, administrar cuentas, prevenir abuso o fraude y cumplir obligaciones legales aplicables. Al solicitar la eliminación, se eliminan la cuenta y los datos asociados. Puede conservarse información limitada cuando sea necesario por seguridad, fraude u obligación legal.

Podés iniciar una solicitud desde Ajustes o consultar la información pública en https://www.hallyuhub.net/delete-account.

Contacto

Para solicitudes de privacidad, escribí a soporte@hallyuhub.net.
